# Artifacts

This directory separates preserved project outputs from current generated data.

- `figures/` contains the historical analysis figures.
- `historical_dashboard/` contains pre-refactor tables retained with characterization tests. They are not compatible with the current app contract.
- `notebooks/legacy/` contains the original output-heavy notebooks. The supported notebooks live in `notebooks/` and call the Python package.

New raw data, processed tracks, and model outputs belong in the ignored `data/` directory. New Streamlit tables belong in `app/data/` and must be generated by `scripts/build_dashboard_data.py`.
