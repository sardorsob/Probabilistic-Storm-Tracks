# Artifacts

This directory contains outputs retained for reference. They are not current pipeline results.

- `figures/` contains legacy analysis figures.
- `historical_dashboard/` contains legacy tables retained with characterization tests. They use an older schema and are not loaded by the current app.

Raw data, processed tracks, and model outputs belong in the ignored `data/` directory. Current Streamlit tables belong in `app/data/` and must be generated by `scripts/build_dashboard_data.py`. See [Results and limitations](../docs/results_and_limitations.md) before interpreting the legacy tables.
